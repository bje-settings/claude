# claude

A [Claude Code plugin marketplace](https://code.claude.com/docs/en/plugin-marketplaces) for the
`bje` enterprise, defined in `.claude-plugin/marketplace.json`. No plugins yet — this is the
scaffold, ready to receive its first one under `plugins/<plugin-name>/`.

Add it locally for testing:

```bash
/plugin marketplace add ./path/to/this/repo
```
