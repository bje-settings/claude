# Simplified Technical English

Write all code comments and all documentation in ASD-STE100 Simplified Technical English
(<https://www.asd-ste100.org/>). Documentation is all Markdown in this repository: READMEs,
`CLAUDE.md`, rules, skills, agents, briefs and records.

Apply the rule to text that you write or change. Do not rewrite other text only to apply it.

## Words

- Use only the approved words of the STE dictionary, with their approved meanings.
- Use technical names (for example `gh`, `worktree`, `SKILL.md`) and technical verbs (for
  example `commit`, `push`, `rebase`) when you must.
- Use one word for one thing. Do not use a different word for the same thing.
- Use a word only as its approved part of speech.
- Do not make noun clusters of more than three words.

## Sentences

- Keep a procedural sentence to 20 words or fewer.
- Keep a descriptive sentence to 25 words or fewer.
- Write one instruction in one sentence.
- Use the imperative for instructions.
- Use the active voice.
- Use only these verb forms: infinitive, imperative, simple present, simple past, simple future,
  and the past participle as an adjective.
- Do not use the "-ing" form of a verb, except in a technical name.
- Do not leave out words to make a sentence shorter. Keep "the", "a" and "that".

## Paragraphs

- Write one topic in one paragraph. Start with the topic sentence.
- Keep a paragraph to six sentences or fewer.
- Use a vertical list for a sequence of steps or for three or more items.
- Start a warning or a caution with a clear command.
