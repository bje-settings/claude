# The plan shape this repository uses

One section per primitive:

1. What is left of the question phase.
2. The stream, with its layers, file sets and sizing.
3. The review loop per layer.
4. The orchestrator's duties.
5. An estimate.
6. Verification.

`skills/stream/brief.md` is the template the plan feeds, so the skill's plan, approved by the
human, answers what that template needs.
