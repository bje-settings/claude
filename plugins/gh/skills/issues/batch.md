# Create two or more related issues

1. Do the duplicate check of [create.md](create.md) step 1 for each issue.
2. Two or more issues with one shared done condition are a milestone. Propose it with
   [milestone.md](milestone.md), "Create for a batch".
3. For each issue, write it with [format.md](format.md) and choose a priority with
   [priority.md](priority.md).
4. Find the relationships in the batch and to other open issues with
   [relationships.md](relationships.md).
5. Show all of the batch in one table (title, type, priority, blocked by, blocking, parent),
   and get one confirmation.
6. Create the milestone first, if there is a new one. Then create the issues in dependency
   order: a blocker before the issue that it blocks. Then each `--blocked-by` number exists
   when you use it. Use the command of [create.md](create.md) step 7.
7. Set the priority on each new issue.
8. Report the batch as one table: number, title, type, priority, relationships, and the
   milestone above it.
