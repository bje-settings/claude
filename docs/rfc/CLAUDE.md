# RFCs

This directory holds all RFCs — reviewed proposals that drive longer-running engineering
initiatives, the engineering-side counterpart to a PRD and broader than a single ADR
(convention: `.claude/rules/path-docs-rfc.md`, shared frontmatter in
`.claude/rules/path-docs.md`). Each RFC is either a single file `NNN-kebab-slug.md` or a
directory `NNN-kebab-slug/README.md`, with status in OKF frontmatter and execution tracked by
milestone in `related_milestones`. `index.md` lists the bundle; landing a new RFC adds its row
in the same PR.
