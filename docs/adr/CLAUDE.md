# ADRs

This directory holds all Architecture Decision Records (convention:
`.claude/rules/path-docs-adr.md`, shared frontmatter in `.claude/rules/path-docs.md`), one file
per ADR named `NNN-descriptive-slug.md` (Context / Decision / Consequences; status lives in OKF
frontmatter, not a body heading). `index.md` lists the bundle; landing a new ADR adds its row in
the same PR.
