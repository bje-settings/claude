# ADRs

This directory holds all Architecture Decision Records (convention:
`.claude/rules/path-docs-adr.md`, shared frontmatter in `.claude/rules/path-docs.md`). One file
holds one ADR, named `NNN-descriptive-slug.md`. Each ADR has three sections: Context, Decision,
and Consequences. Status lives in OKF frontmatter, not a body heading. `index.md` lists the
bundle. When you land a new ADR, add its row in the same PR.
